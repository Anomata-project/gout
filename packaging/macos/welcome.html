gout, a command-line DAW

gout stacks wav and mp3 tracks on a timeline, mixes them through effect chains and plays the song, from Terminal: as commands, or in its own full-screen interface with waveforms and a fractal that moves with the music.

This installs:

  • gout in /usr/local/bin, so every Terminal window has it
  • gout in Applications, which opens Terminal in a gout folder in your home
  • ffmpeg, which gout uses for sound, inside gout's own folder (/usr/local/lib/gout)
